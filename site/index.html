// what it does

The parts of Spotify you use every day, without the parts you don't.

▍light

One small native program, written in Rust, with no browser inside: under 20 MB while it plays, window open or closed.

j/k keyboard first

Move, play, search, skip, seek, like, switch panes. Every action has a key, vim-style, and the mouse still works.

♪ synced lyrics

Lyrics follow the song line by line, from LRCLIB. Click a line to jump there.

≡ a real queue

See what plays next, in shuffle order, and jump to any upcoming track. Put songs up next or take them out. Shuffle and repeat (all / one) included.

/ search & library

Liked Songs, all your playlists (followed ones and Spotify's mixes too), and search across tracks, albums and artists. Make playlists and add or remove songs, several at once, from a right-click menu. Songs already there aren't added twice.

◎ song radio

Press R on any song for an endless station of songs like it. The player always shows what it's playing from.

◐ your look

Eleven palettes or one of your own, three pane styles (minimal, boxed, glass), any accent colour, or colours from the playing cover.

⏯ fits in windows

Media keys, the Windows media overlay with cover art, and a tray menu. Turn on the mini player there for previous, play/pause, next and volume right in your taskbar.

⇄ a real device

spotini shows up in your Spotify account like any other speaker, so what you play shows wherever Spotify shares it, such as your Discord status.

320 kbps

Streams at Spotify's highest Premium quality (Ogg Vorbis, 320 kbps) through librespot.

◇ private

Talks only to Spotify and, for lyrics, LRCLIB. No account of ours, no analytics; your login stays in Windows Credential Manager.

{} free & open

MIT licensed, no ads, no upsell. Every download is built from the public source by GitHub Actions.

// setup

About five minutes, once. Spotify requires every app like this to use your own (free) developer app.

  1. download & run

    Get spotini-setup.exe. It isn't code-signed, so Windows may say "Windows protected your PC": choose More info → Run anyway.

  2. create a spotify app

    At developer.spotify.com/dashboard, create an app with redirect URI http://127.0.0.1:8899/callback and Web API ticked. Copy its Client ID.

  3. log in & paste

    Log in with Spotify in spotini, paste the Client ID, and connect your library. It remembers both.

// faq

Do I need Spotify Premium?

Yes. Spotify only allows playback in third-party apps for Premium accounts.

Is this official?

No. spotini is an independent open-source project, not made, endorsed or supported by Spotify. Playback uses librespot, an open-source Spotify client library.

Why do I need my own Client ID?

Since February 2026 Spotify limits each developer app to five users, so a shared ID can't work for everyone. Your own app is free and takes two minutes.

Do followed playlists and Spotify's mixes work?

Yes. Spotify's Web API only lists the tracks of playlists you own, so spotini loads followed playlists, Daily Mixes and song radio through Spotify's internal endpoints, the same way it plays music. Like playback, that's unofficial and could break if Spotify changes it.

Where are my login details stored?

In Windows Credential Manager on your PC. spotini talks only to Spotify and, for lyrics, to LRCLIB. There's no analytics, and this website has no tracking either.

Is there lossless audio?

No. librespot streams up to 320 kbps Ogg Vorbis, Spotify's highest quality before lossless.

macOS or Linux?

Windows only for now. spotini is built with Rust and Slint, which run elsewhere too, so other platforms are possible later.
