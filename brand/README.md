# spotini brand

Logos, colours and type. Open [`index.html`](index.html) for the full guide.

| Folder | What's in it |
| --- | --- |
| `logo/` | `icon`, `mark-*`, `wordmark-*` and `lockup-*` as SVG, with PNGs in `logo/png/` |
| `social/` | `og-image` (1280×640) for link previews |
| `favicon/` | `favicon.svg` and PNGs |

Variants: `dark` and `light` (for dark and light backgrounds), `mono-dark` and `mono-light` (one colour).

Everything is generated by [`build.mjs`](build.mjs):

```bash
npm run brand
```

It also writes the app's icon, `app/icon.ico`.
